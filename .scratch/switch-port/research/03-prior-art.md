# 03 — Prior art: Godot ports to Nintendo Switch homebrew

Ticket: "Prior art: existing Godot ports to Switch homebrew". Target of this fork: Godot 4.7.2-stable, Compatibility (GLES3) renderer, devkitA64 + libnx, direct libnx HID (no SDL2), `.pck` beside the NRO on SD. Researched 2026-10-13 by reading the repositories directly (raw files and the GitHub API); every claim cites a file or commit. Note: the GitHub REST rate limit was hit mid-way, so a few listings were taken from the rendered GitHub pages instead of the API; this is called out where it matters.

## Summary

1. Two real native ports exist: **Stary2001/godot** (Godot 3.1.1 → 3.5.2, 2018–2023, mature, shipped games) and **Ozuba/godot** `switch-platform` (Godot 4.7-rc, Jun–Sep 2026, self-described "heavily vibecoded", builds and boots; GLES3 + Vulkan/NVK).
2. The only other Godot 4 attempt, **halotroop2288/godot** `4.x-switch` (4.1-dev, one WIP commit, May 2023), never compiled: its `os_switch.h` still includes Godot 3 headers. Dead end except for its `drivers/audren` sketch.
3. **Homebrodot/platform-switch** is Stary's 3.5 code re-homed as a sub-repo (last touched Nov 2024, no 4.x branch). **Thorhax/Gizmoduck-NX-Modern** is not a port: it loads a game's `libgodot_android.so` (Godot 4.7.2) behind a fake JNI/Bionic shim.
4. Recommendation: lift Ozuba's 4.7 platform layer wholesale as the skeleton (`detect.py`, `platform_thread.*` with `PLATFORM_THREAD_OVERRIDE`, `OS_Switch`, `DisplayServerSwitch` EGL path, `AudioDriverSwitch` audren, `JoypadSwitch`, the `HORIZON_ENABLED` guards in `drivers/unix`, `drivers/gles3` and thirdparty), and drop its Vulkan/NVK and Mesa-26 "unified SDK" dependency unless the renderer ticket decides stock `switch-mesa` 20.1 is insufficient for GLES3.
5. From Stary take the battle-tested pieces Ozuba lacks: the applet-mode guard/splash in `main()`, the hbmenu `fileassoc` config + forwarder NRO for ".pck beside NRO" launching, and the C++ exporter that rewrites the NRO `ASET` section (icon/NACP/RomFS) using `thirdparty/libnx/nro.h,nacp.h`.
6. Everybody uses `audren` (audio renderer via `audrv`), never `audout`; everybody creates the GL context with EGL on `nwindowGetDefault()` with `EGL_CONTEXT_CLIENT_VERSION 3`; everybody maps `user://` to `sdmc:/switch/godot/app_userdata/<name>`.
7. Threads: both ports use newlib pthreads via `init_thread_posix()` + `PTHREAD_NO_RENAME`; Ozuba additionally replaces `core/os/thread.cpp` with a pthread version that sets a 2 MiB stack because libnx defaults pthread stacks to 128 KiB (`libnx/nx/source/runtime/newlib.c`).
8. Open question handed to the renderer ticket: Godot 4.7 Compatibility on devkitPro's `switch-mesa` 20.1.0-rc3 (nvc0) has not been demonstrated by anyone; Ozuba only ran GLES3 through Mesa 26.2 (zink-over-NVK or nvc0) from a community Mesa port, not from portlibs.

## Findings per port

### 1. Stary2001/godot — Godot 3.x (3.1.1 → 3.5.2), 2018–2023

- Repo: https://github.com/Stary2001/godot. Fork of godotengine/godot; default branch `3.5.2-stable_switch`; last push 2023-05-19; 416 stars (GitHub API `/repos/Stary2001/godot`). Branches per engine version: `3.1.1-stable_switch` … `3.5.2-stable_switch`, plus `3.5.2-stable_switch_refactor`. Releases: `v3.2.1-stable-switch` (2020-06-17) … `v3.5.1-stable_switch_fixed` (2023-03-02) (`/repos/Stary2001/godot/releases`).
- Lineage: first commit "Initial switch thing" `b4a2e83a88` (2018-09-10, Ezekiel/Chloe Bethel). cpasjuste added export (`b98f8ca88a`, `289c55da1f` ".pck exports working" 2019-04-13), joypads (`62513758f1` 2019-04-14), the audio driver (`569b9804e0` 2019-05-11), NACP/icon export (`7c97959bde` 2019-06-07). fhidalgosola merged a build-script cleanup (`463c445a5f`). All from the compare `godotengine/godot:3.5.2-stable...Stary2001:3.5.2-stable_switch` (134 commits ahead).
- Files (`platform/switch/` on `3.5.2-stable_switch`): `SCsub`, `detect.py`, `os_switch.{cpp,h}`, `godot_switch.cpp`, `context_gl_switch_egl.{cpp,h}`, `audio_driver_switch.{cpp,h}`, `joypad_switch.{cpp,h}`, `power_switch.{cpp,h}`, `switch_wrapper.h`, `platform_config.h`, `godot.cfg`, `export/export.{cpp,h}`, `romfs/applet_splash.rgba.gz`, `Info.plist`. Changes outside the platform dir: `core/project_settings.cpp`, `drivers/unix/{file_access,dir_access,ip,net_socket_posix}*.cpp`, `drivers/gles2|gles3/rasterizer_storage_*.cpp`, `modules/bullet/SCsub`, `thirdparty/libnx/{nacp,nro,types}.h`, `scripts/create-switch-{release,template}.sh`, `.github/workflows/switch_builds.yml`.

How it solved each area:

- **Build/toolchain** (`platform/switch/detect.py`): `aarch64-none-elf-gcc/g++`, `-march=armv8-a -mtune=cortex-a57 -mtp=soft -fPIE -ffunction-sections`, `-isystem $DEVKITPRO/libnx/include`, `-specs=$DEVKITPRO/libnx/switch.specs`, defines `__SWITCH__ POSH_OS_HORIZON HORIZON_ENABLED LIBC_FILEIO_ENABLED OPENGL_ENABLED GLES_ENABLED PTHREAD_ENABLED PTHREAD_NO_RENAME`, libs `EGL GLESv2 glapi drm_nouveau nx`; most thirdparty taken from portlibs via `aarch64-none-elf-pkg-config` (freetype, png, theora, vpx, vorbis, opus, webp, mbedtls, wslay, miniupnpc, pcre2, zstd), `builtin_bullet/enet/squish=True`. `README.md` lists the pacman packages: `switch-pkg-config switch-freetype switch-bulletphysics switch-libtheora switch-libpcre2 switch-mesa switch-opusfile switch-mbedtls switch-libwebp switch-libvpx switch-miniupnpc switch-libzstd switch-wslay`. CI builds in the `devkitpro/devkita64` container (`.github/workflows/switch_builds.yml` line 30).
- **Threads**: newlib pthreads. `OS_Switch::initialize_core()` calls `init_thread_posix()` (`os_switch.cpp`); commit `fb1aee90d5` "switch to pthreads, switch to wrapping libnx instead of horrific sed everywhere" (2019-03-16) and cpasjuste `bfb64d9055` "use posix (pthread) locks and semaphores". `switch_wrapper.h` `#define`s `Mutex/Semaphore/Thread/AudioDriver` to `Libnx*` around `#include <switch.h>` to avoid name clashes with Godot core types. `OS_Switch::get_render_thread_mode()` downgrades `RENDER_SEPARATE_THREAD` to `RENDER_THREAD_SAFE` (commit `a1391dcc6a` "Force never using RENDER_SEPARATE_THREAD because it's broken on switch", Álex Román Núñez, 2021-07-11). The audio thread raises its own priority with `svcSetThreadPriority(CUR_THREAD_HANDLE, 0x2B)` (`audio_driver_switch.cpp`).
- **GL/EGL** (`context_gl_switch_egl.cpp`): `eglGetDisplay(EGL_DEFAULT_DISPLAY)` → `eglInitialize` → `eglChooseConfig` (RGBA 8888, depth 24, stencil 8) → `eglCreateWindowSurface(display, config, nwindowGetDefault(), NULL)` → `eglCreateContext` with `EGL_CONTEXT_CLIENT_VERSION 3` → `eglMakeCurrent`. Window size hard-coded 1280×720 (`get_window_width/height`, `OS_Switch::get_video_mode`); no docked-mode handling. `OS_Switch::initialize()` tries GLES3 then falls back to GLES2 per `rendering/quality/driver/fallback_to_gles2`. Driver stack is devkitPro's `switch-mesa` portlib, which is Mesa **20.1.0-rc3** (`devkitPro/pacman-packages/switch/mesa/PKGBUILD`, `pkgver=20.1.0`, depends `switch-libdrm_nouveau`). Export templates fake `s3tc_supported = false` (`drivers/gles2/rasterizer_storage_gles2.cpp` diff, "Switch: this happens on Horizon too").
- **Audio** (`audio_driver_switch.cpp`): `audren` via `audrv`. `AudioRendererConfig{48 kHz, 24 voices, 0 effects, 1 sink, 1 mix obj, 2 mix buffers}`; `audrenInitialize` → `audrvCreate(&drv, &cfg, 2)`; one `memalign(0x1000)` pool holding two `AudioDriverWaveBuf`s of `buffer_size` frames; `audrvMemPoolAdd/Attach`; `audrvDeviceSinkAdd(AUDREN_DEFAULT_DEVICE_NAME, 2, {0,1})`; `audrenStartAudioRenderer`; one voice `audrvVoiceInit(..., PcmFormat_Int16, mix_rate)` with a 2×2 mix-factor matrix. Thread loop: `audio_server_process` → int32→int16 (`>> 16`) → `memcpy` into the free wavebuf → `armDCacheFlush` → `audrvVoiceAddWaveBuf` → `audrvVoiceStart` if idle → `audrvUpdate` → `audrenWaitFrame` → spin `audrvUpdate` until the buffer reports `Playing`. `buffer_size = closest_power_of_2(latency * mix_rate / 1000)`. No `audout` anywhere.
- **Input** (`joypad_switch.cpp`, `os_switch.cpp`): `padConfigureInput(1, HidNpadStyleSet_NpadStandard)`; eight `PadState`s initialised with `padInitializeWithMask` where pad 0's mask is `No1|Handheld`; per frame `padUpdate`, sticks `padGetStickPos / 32767.0f`, buttons from `padGetButtonsUp/Down` against a positional table (`B,A,Y,X,L,R,ZL,ZR,StickL,StickR,Minus,Plus,Up,Down,Left,Right`) indexed by Godot 3 button number. All 8 pads are pre-registered connected (`joy_connection_changed(i, true, "pad"+i)`). Touch: `hidInitializeTouchScreen()` + `hidGetTouchScreenStates()` polled in `OS_Switch::run()`, diffed against the previous count to emit `InputEventScreenTouch/ScreenDrag` (up to 16). Virtual keyboard: libnx inline swkbd (`swkbdInlineLaunchForLibraryApplet`, string/cursor/enter/cancel callbacks turned into key events). Commit `f61252c064` "update to new hid api" (2021-07-11) moved to the `pad*` API. Commit `9e8ec55115` "Flush input events. This is the only thing that broke the new version." adds `input->flush_buffered_events()` in the loop.
- **File paths**: `FileAccessUnix/DirAccessUnix/NetSocketPosix/IP_Unix` reused by extending their `#if defined(UNIX_ENABLED)` guards with `|| defined(HORIZON_ENABLED)` (`drivers/unix/*.cpp` diff vs 3.5.2-stable); `DirAccessUnix::read_link/create_link` stubbed (`120b482719`); `IP_Unix::get_local_interfaces` is an empty "todo: nifm". `OS_Switch::get_data_path()` returns `"sdmc:/switch"`; `get_user_data_dir()` → `sdmc:/switch/godot/app_userdata/<name>` (or the custom dir). `get_executable_path()` is `argv[0]` as passed by hbmenu/nxlink (`918696b1d0` "fix get_executable_path, this allow pck loading"), so the stock exec-basename `.pck` lookup works. `core/project_settings.cpp` gains a `HORIZON_ENABLED` fallback `_load_resource_pack("romfs:/game.pck")` when no pack was found; `main()` always calls `romfsInit()` (`4a235a5b29` "export: actually set romfs offset, switch: always romfsinit"). `platform/switch/godot.cfg` is an hbmenu `fileassoc` entry: `.pck` files launch `/switch/godot/godot-forwarder.nro` with `app_args = ["--main-pack", "%f"]` (`836a2af9fb` "use new app_args fileassoc feature"). The separate **Stary2001/godot-forwarder** repo ("Small NRO that sits in front of Godot Engine … to select the right engine version", `Makefile` + `source/`) is what the release zip ships next to `godot-<ver>.nro` (`scripts/create-switch-release.sh`).
- **Packaging** (`SCsub`, `export/export.cpp`): `SCsub` runs `nacptool --create Godot 'Stary & Cpasjuste' <ver>` then `elf2nro $SOURCE $TARGET --icon=icon.jpg --nacp=nacp_default.nacp --romfsdir=platform/switch/romfs` (the romfs carries only `applet_splash.rgba.gz`). `main()` in `godot_switch.cpp` checks `appletGetAppletType()`; if not `AppletType_Application/SystemApplication` it draws the splash to a libnx `Framebuffer` and exits on any button (homebrew-menu applet mode lacks memory). The editor exporter (`export/export.cpp`, 596 lines, a 3.x `EditorExportPlatform`) opens the template NRO, verifies the `NRO0` and `ASET` magics, copies the body, then rewrites the asset section with the preset's 256×256 JPEG icon, a freshly built `NacpStruct` (title/author/version via `create_nacp`), and either the template RomFS or, for `application/fused_build`, a RomFS built with devkitPro's `build_romfs` that contains `game.pck` + the splash (`create_nro()` lines 442–532). Non-fused export writes `<name>.pck` beside `<name>.nro`. One-click deploy shells out to `nxlink` (editor setting `export/switch/nxlink`). The exporter needs `thirdparty/libnx/{nro.h,nacp.h,types.h}` ("Use actual libnx headers", `172e1e43a2`).

### 5. Ozuba/godot `switch-platform` — Godot 4.7-rc, Jun–Sep 2026 (the only working Godot 4 port)

- Repo: https://github.com/Ozuba/godot, description "A heavily vibecoded Godot LibNX port"; not a GitHub fork (created 2026-06-10, last push 2026-09-12, 0 stars); branches `master`, `switch-platform` (default), `switch-platform-nvk`. `version.py` = 4.7.0-rc. Port commits on top of upstream `ec67cbe926` (2026-06-09): `964b17fb91` "First compilable implementation", `6f2c716484` "Improvements and jit support for regex", `337b2a5d93` "Fixed support for NRO romfs packing", `511701a04d` "Improvements in logging, revamped thread management to support bigger stacks", `c1567561e4` "Fixes to handled-tv resizing fallback, and user folder correction", `ded7c60559` "Initial proof of concept vulkan port", `2b77d2ec93` "Testing with new nvk compilation", `e5c78a258b` "Partial working state, restored servers to upstream" (compare `ec67cbe926...switch-platform`: 8 commits).
- Files (`platform/switch/`): `README.md`, `SCsub`, `detect.py`, `os_switch.{cpp,h}`, `display_server_switch.{cpp,h}`, `audio_driver_switch.{cpp,h}`, `joypad_switch.{cpp,h}`, `godot_switch.cpp`, `platform_thread.{cpp,h}`, `platform_config.h`, `platform_egl.h`, `platform_gl.h`, `platform_mbedtls_config.h`, `rendering_context_driver_vulkan_switch.{cpp,h}`, `entropy_switch.cpp`, `crash_handler_switch.cpp`, `switch_logger.{cpp,h}`, `switch_wrapper.h`, `icon.jpg`. Outside: `drivers/unix/{file_access,dir_access,ip,net_socket,thread_posix}*`, `drivers/gles3/{rasterizer_gles3.cpp,storage/render_scene_buffers_gles3.cpp,storage/texture_storage.cpp}`, `drivers/vulkan/rendering_context_driver_vulkan.cpp`, `modules/regex/{SCsub,regex.cpp}`, `modules/websocket/SCsub`, `modules/jolt_physics/spaces/jolt_temp_allocator.cpp`, and thirdparty guards in `jolt_physics/Jolt/Core/Core.h`, `mbedtls/library/timing.c`, `volk/volk.c`, `enet/enet/enet_godot.h`, `manifold/src/svd.h`, `basis_universal/encoder/basisu_enc.cpp`, `pcre2/deps/sljit/sljit_src/{sljitLir.c,allocator_src/sljitProtExecAllocatorHorizon.c}`.

How it solved each area:

- **Build/toolchain** (`detect.py`): `can_build()` requires `$DEVKITPRO/devkitA64` and `/libnx`; flags copied from `switchvars.sh`: `-march=armv8-a+crc+crypto -mtune=cortex-a57 -mtp=soft -fPIE -ftls-model=local-exec -ffunction-sections -fdata-sections`, link `-specs=libnx/switch.specs -Wl,--gc-sections`; defines `__SWITCH__ HORIZON_ENABLED POSH_OS_HORIZON PTHREAD_NO_RENAME`; `get_flags()` sets `arch=arm64`, `vulkan=True`, `use_volk=False`, `opengl3=True`, `sdl=False`, `accesskit=False`, `builtin_pcre2_with_jit=True`, disables `module_raycast/upnp/camera`, and `disable_path_overrides=False` (so templates accept `--main-pack`). Links `EGL GLESv2 glapi vulkan vulkan_util mesa_util mesa_util_c11 mesa_util_simd blake3 expat z zstd nx m`. The graphics stack is **not** the devkitPro portlib: `mesa_sdk_path` points at a "unified Mesa Horizon SDK" prefix (`mesa-26.2.1-switch-unified-horizon-sdk/opt/devkitpro/portlibs/switch`) built from **danfromtico/mesa-switch** (Ozuba forks it; its README: "Based on Mesa 26.2.4", "NVK, built loaderless", "Gallium NVC0 by default, or Zink layered on top of NVK", "Everything links statically into an NRO/NSO", selector `MESA_SWITCH_GL_DRIVER=zink|nvc0` read at `eglInitialize`).
- **Threads**: `platform_config.h` defines `PLATFORM_THREAD_OVERRIDE` (upstream hook, see `core/os/thread.h` lines 35–39 in this worktree), and `platform_thread.{h,cpp}` is a pthread-based `Thread` with `STACK_SIZE = 2 * 1024 * 1024` passed via `pthread_attr_setstacksize`. Rationale in the header: "threads on libnx default to 128 KiB stacks … Jolt's narrowphase running on WorkerThreadPool threads overflows that". Verified against libnx: `nx/source/runtime/newlib.c` `__syscall_thread_create` uses `stack_size = 128*1024` when none is given and creates the thread at priority `0x3B` on core `-2`. `OS_Switch::initialize()` still calls `init_thread_posix()`; `drivers/unix/thread_posix.cpp` guard extended to `HORIZON_ENABLED`; `get_processor_count()` returns 3. `switch_wrapper.h` adds `Event` and `Framebuffer` to the renamed libnx types.
- **GL/EGL** (`display_server_switch.cpp`): a real `DisplayServer` registered as `"switch"` (`register_create_function("switch", ...)`) advertising `vulkan` and `opengl3`. `_initialize_egl()`: `eglGetDisplay(EGL_DEFAULT_DISPLAY)` → `eglInitialize` → `eglBindAPI(EGL_OPENGL_ES_API)` → `eglChooseConfig` with `EGL_RENDERABLE_TYPE EGL_OPENGL_ES3_BIT`, RGBA8/D24/S8 → `nwindowSetDimensions(nwindowGetDefault(), 1920×1080 or 1280×720)` depending on `appletGetOperationMode()` → `eglCreateWindowSurface` → `eglCreateContext` (`EGL_CONTEXT_CLIENT_VERSION 3`) → `eglMakeCurrent`; then `RasterizerGLES3::make_current(false)` and `eglSwapInterval` for vsync. Docked/handheld switches are detected with `appletHook` on `AppletHookType_OnOperationMode/OnResume` and handled in `_update_operation_mode()` by destroying and recreating the EGL surface after `nwindowSetDimensions`, then firing the rect-changed callback. `swap_buffers()` = `eglSwapBuffers`; `release_rendering_thread()` = `eglMakeCurrent(NO_SURFACE…)`; `window_get_native_handle` exposes the nwindow, EGL display and context. `platform_gl.h` includes `<GLES3/gl32.h>`. Engine-side: `drivers/gles3/rasterizer_gles3.cpp` adds `HORIZON_ENABLED` to the `EGL_ENABLED || ANDROID_ENABLED` blocks, and `render_scene_buffers_gles3.cpp` / `texture_storage.cpp` add `HORIZON_ENABLED` to the `#ifndef IOS_ENABLED` exclusions (the same code paths iOS skips). Vulkan path: `RenderingContextDriverVulkanSwitch` uses `VK_NN_VI_SURFACE_EXTENSION_NAME` and `vkCreateViSurfaceNN` on the nwindow, no validation layers; `godot_switch.cpp` sets `NVK_I_WANT_A_BROKEN_VULKAN_DRIVER=1`, `RAYON_NUM_THREADS=1`, `MESA_SHADER_COMPILER_THREADS=1`, `NVK_DEBUG=no_compression`, `MESA_SHADER_CACHE_DIR=sdmc:/switch/godot`. README limitations: NVK WSI is FIFO-only; NVK needs title takeover ("boot as application"), not applet mode.
- **Audio** (`audio_driver_switch.cpp`): same `audren`/`audrv` design as Stary, modernised for 4.x (`audio/driver/output_latency`, `_get_configured_mix_rate()`, `SafeFlag active/exit_thread`, `R_FAILED` checks, pool freed in `finish()`, exit check inside the `Playing` spin). Runs on a Godot `Thread` (so it gets the 2 MiB stack). No `svcSetThreadPriority`. README: "stereo, 48 kHz device rate, mixed at the project mix rate on a dedicated thread".
- **Input** (`joypad_switch.cpp`, `display_server_switch.cpp`): `padConfigureInput(8, HidNpadStyleSet_NpadFullCtrl)` + `hidSetNpadJoyHoldType(HidNpadJoyHoldType_Horizontal)`; per pad `padUpdate`, `padIsConnected` drives `joy_connection_changed` with a style name (`Pro Controller`, `Switch Handheld`, `Joy-Con (Dual/L/R)`) and `info["mapping_handled"] = true`; buttons mapped positionally to Godot's SDL layout (`HidNpadButton_B → JoyButton::A`, etc.) with separate rotated tables for a single sideways Joy-Con (L and R), sticks rotated accordingly; `ZL/ZR` emitted as `TRIGGER_LEFT/RIGHT` axes; rumble via `hidInitializeVibrationDevices` + `hidSendVibrationValues` driven from `Input::get_joy_vibration_*`; motion via `hidGetSixAxisSensorHandles/hidGetSixAxisSensorStates` → `set_accelerometer/set_gyroscope` (G→m/s², rev/s→rad/s) for pad 0. Touch and the inline swkbd live in `DisplayServerSwitch` (`_process_touch`, `virtual_keyboard_show/hide/get_height`, `FEATURE_TOUCHSCREEN/VIRTUAL_KEYBOARD`). `process_events()` order: operation-mode check, `swkbdInlineUpdate`, touch, `OS_Switch::process_joypads()`, `Input::flush_buffered_events()`.

Engine log goes to `sdmc:/godot_boot.log` via a custom `Logger` (`switch_logger.cpp`), crashes to `sdmc:/godot_crash.log` via `__libnx_exception_handler` with a frame-pointer backtrace relative to the module base (`crash_handler_switch.cpp`). Startup failures are shown with the system error applet (`errorSystemCreate/Show`). mbedTLS entropy from `randomGet` (`entropy_switch.cpp`, `platform_mbedtls_config.h`); `posix_memalign`, `dirname`, `basename` shims for newlib.

[--icon=icon.jpg]`; keeps `.symtab` in the ELF for offline symbolising; outputs `bin/godot.switch.<target>.arm64{,.nro}`. No `--romfsdir`. ### 6. Thorhax/Gizmoduck-NX-Modern — a loader for Android Godot 4.7.2, not a port (Sep 2026)

- Repo: https://github.com/Thorhax/Gizmoduck-NX-Modern, MIT, 2 commits, last push 2026-09-17; description "Modern Godot 4.7 Android ARM64 wrapper with GLES3 for Horizon OS". README: it "dynamically loads the ARM64 Android engine library (`libgodot_android.so`)" and "recreates Android, JNI, audio, input, and graphics services" on the Switch, rendering "OpenGL ES 3.0 via Switch Mesa & deko3d" with a shader cache under `save/cache/mesa`; must be launched via Title Override because "Applet mode (Album) … will fail to allocate the required heap for the Godot engine". `source/` holds ~75 C files (`jni_fake.c`, `godot_shim.c`, `egl_shim.c`, `audio_sink.c`, `nx_input.c`, `swkbd_shim.c`, `so_util.c`, `bionic_*.c`, `libc_shim.c`, …).
- Relevance: evidence that a Godot 4.7.2 GLES3 build renders on the Tegra X1 through a Mesa EGL stack and that homebrew applet-mode memory is a real constraint; the technique (ELF loader + fake JNI/Bionic) is not applicable to a native `platform/switch`.

## Dead ends

- **halotroop2288/godot `4.x-switch`**: never compiled (3.x headers, `VisualServer`, missing `DisplayServer`, broken audren driver). Do not base anything on it beyond the exporter file layout.
- **Stary's engine-integration code**: `OS_Switch::initialize()` GL fallback loop, `VisualServerWrapMT`, `get_render_thread_mode()` override, `ContextGLSwitchEGL` class, `power_switch.*`, `InputDefault` wiring, GLES2 paths, the `rasterizer_storage_gles2/gles3` S3TC hacks — all Godot 3 architecture with no 4.x counterpart (superseded by Ozuba's `DisplayServerSwitch`).
- **Stary's fixed 1280×720** window and absent docked-mode handling.
- **Stary's `OS_Switch::execute()`** `envSetNextLoad` trick for running the editor on-device; irrelevant for templates.
- **Ozuba's Vulkan/NVK stack** for this ticket's scope: requires the non-portlib Mesa 26.2 "unified SDK" (danfromtico/mesa-switch, `build-unified.sh`, MSYS2 toolchain), `NVK_I_WANT_A_BROKEN_VULKAN_DRIVER`, title takeover, FIFO-only vsync, single-threaded NAK. Keep the `rendering_context_driver_vulkan_switch.*` files out of the initial port. Caveat: Ozuba's GLES3 was only exercised through that same SDK (zink or Mesa-26 nvc0); nobody has yet run Godot 4.x Compatibility on devkitPro's `switch-mesa` 20.1.0-rc3 nvc0 — Stary only proved Godot 3's GLES3 renderer there.
- **Ozuba's GDScript export addon**: documented in its README but not present in the repository.
- **Ozuba's PCRE2 JIT allocator** (`sljitProtExecAllocatorHorizon.c`, `jitCreate`): optional; skip unless regex performance matters.
- **Thorhax/Gizmoduck-NX-Modern**: a loader for Android `.so` builds, not a platform port.
- **giodotblue/godot-switch-libnx**: misnamed vanilla snapshot.
- **`audout`**: no port uses it; `audren` is the proven path.
